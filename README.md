# 蒸汽红楼（暂名）

微信小游戏原型：放置三合一（学《三重小镇》）+ 肉鸽（学《小丑牌》《哈迪斯》），题材是宫崎骏式蒸汽朋克 + 红楼，黄昏暖光。

- 在线试玩：https://chuyuanwritings-max.github.io/cybor-honglou/
- 当前版本：原型 2.4（8 比特代码绘制，数值初调）

## 怎么玩

- 手里来什么就放哪里，三个一样挨在一起合成高一级：铜籽 → 嫩芽 → 花 → 花丛 → 海棠树 → 铜亭 → 钟楼。
- 一季三关共用一盘棋，不清空；棋盘满了就输，分数达标就过关，剩下的空地变养料。
- 发条机会出现在手里，放下后每回合乱走；把它围得走不动，就停摆成废齿轮。
- 每季一张地图：断格不能放，铜盘格上合成分数 ×2。每季第 3 关有 Boss（煤雨、汽笛、狂风、霜冻）。
- 打完一关回到自己的浮空园子「太虚」（脚下是云海和小镇）：用合出来的东西摆园子，种出植物、动物、奇珍；下一关前从养成的里面三选一带上。
